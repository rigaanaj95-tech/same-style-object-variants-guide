Same Style Object Variants

一个把参考图风格迁移到新物体、场景或素材上的可复用 Codex skill。它先读懂参考图，再生成提示词、批量方案、筛选和返工建议。

基于参考图生成同风格物体、场景和素材变体。

Download Package →

Extracts style DNA before generating variants.

6 steps from reference image to usable assets.

Follows the current reference style, not a fixed green platform or forced realism.

Workflow

Skill 如何工作

每一次调用都以当前参考图为准。参考图是手绘，就跟随手绘；参考图是摄影，才进入真实产品摄影感。

01

识别输入

确认参考图、目标物体或场景、数量、视角、用途和必须保留的限制。

02

提取风格

分析媒介、构图、色彩、线条、材质、光影、字体和视觉层级。

03

生成提示词

把风格 brief 转成可直接用于 image2 或其他生图工具的 prompt。

04

批量变体

输出多组方向，并围绕摆放、比例、数量、视角和画面用途调整。

Invocation

如何调用

触发词建议直接写在任务开头，这样 Codex 能明确进入这套工作流。

最短调用：

使用 $same-style-object-variants，帮我基于这张参考图生成同风格物体变体。
目标物体：一个沙发

更完整调用：

使用 $same-style-object-variants，帮我基于这张参考图生成同风格场景变体。
目标场景：一个舒适的家居场景
数量：生成 3 个方向
用途：社媒海报素材
要求：跟随参考图画风，不要强制写实

安装方式

下载压缩包后解压，将 same-style-object-variants 文件夹复制到 Codex skills 目录。

mkdir -p ~/.codex/skills
cp -R same-style-object-variants ~/.codex/skills/

常用返工语句

  • 不要写实，严格跟随参考图的插画/平面/手绘风格。
  • 只参考当前这张图，不要继承历史生成结果。
  • 只生成 1 个主体物体，不要额外添加同类物体。
  • 文字只作为版式元素，不需要真实可读。

适合做什么

促销海报素材、产品目录页、手绘插画变体、社媒视觉探索、同风格物体替换、场景氛围延展。

不做什么

不把所有参考图都变成绿色展台；不默认改成写实；不把历史图像风格带入下一次任务。
