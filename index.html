Codex Skill Guide

Same Style
Object Variants

一套把“参考图风格”迁移到新物体、场景或素材上的 Codex skill。默认跟随参考图媒介和画风，不强制写实。

Explicit trigger
$same-style-object-variants
  • 参考图是手绘，就生成手绘；参考图是摄影，才生成摄影。
  • 先提炼风格 DNA，再替换目标物体或场景。
  • 支持 prompt、image2 生图、筛选返工和后期建议。

01 / Capability

它解决什么问题

$same-style-object-variants 用来基于一张参考图，生成同风格的物体、场景或素材变体。它会提取参考图的媒介、画风、构图、配色、字体、线条、材质和主体关系，再把你的目标替换进去。

不默认写实

除非用户明确说“写实”或“真实摄影感”，否则优先匹配参考图本身的风格。

不继承历史风格

每次任务都以当前参考图为唯一风格来源，避免被上一张图污染。

支持多种对象

可以生成物体、场景、材质、促销海报素材、社媒图、设计探索图。

支持继续生图

当 image2、即梦、Lovart 或 ChatGPT 图像生成可用时，可以进入生成和迭代。

02 / Installation

安装方式

把压缩包解压后，将 same-style-object-variants 文件夹复制到 Codex skills 目录。

mkdir -p ~/.codex/skills
cp -R same-style-object-variants ~/.codex/skills/

安装后目录应类似：

~/.codex/skills/same-style-object-variants/
├── SKILL.md
├── agents/
│   └── openai.yaml
└── references/
    ├── prompting.md
    └── quality-check.md
03 / Invocation

推荐调用方式

最短调用：

使用 $same-style-object-variants，帮我基于这张参考图生成同风格物体变体。
目标物体：一个沙发

更完整调用：

使用 $same-style-object-variants，帮我基于这张参考图生成同风格场景变体。
目标场景：一个舒适的家居场景
数量：生成 3 个方向
用途：社媒海报素材
要求：跟随参考图画风，不要强制写实

如果确实想要写实：

使用 $same-style-object-variants，帮我基于这张参考图生成同风格写实物体变体。
目标物体：一盏灯具
要求：保持参考图构图，但产品本身要真实摄影感
04 / Inputs

给它什么信息，结果更稳

参考图

最好直接上传图片；没有图时用清楚的风格描述代替。

目标对象

说明要替换成什么物体、场景或材质。

数量与用途

例如 1 张、3 组方案；用途是海报、素材还是设计探索。

风格约束

明确“跟随画风”或“需要写实”，避免模型自行切换媒介。

05 / Workflow

skill 的工作流程

识别参考图风格

提取媒介、画风、构图、颜色、字体、线条、材质、光影和主体比例。

生成风格 brief

把参考图风格变成一段可复用、可迁移的描述。

替换目标

保留参考图风格，只替换用户指定的物体、场景或材质。

生成提示词

输出适合生图工具直接使用的 prompt、避免项和变体策略。

生图与批量探索

工具可用时直接进入生成；否则给出可复制的 prompt。

筛选与返工

检查结果是否贴合参考图媒介、画风、构图、配色和排版。

07 / Repair Notes

常见问题与返工语句

结果太写实

补一句：不要写实，严格跟随参考图的插画/平面/手绘风格。

继承了上一张图

补一句：只参考当前这张图，不要继承历史生成结果。

物体数量不准

补一句：只生成 1 个主体物体，不要额外添加同类物体。

文字容易乱

补一句：文字只作为版式元素，不需要真实可读，不要出现品牌 logo。

08 / Share

如何让飞书里的同事都能打开

当前 file:// 链接只指向你的本机文件，别人点击会失效。要让团队访问，需要把 HTML 变成一个云端可访问地址，或者转成飞书文档内容。

推荐：转成飞书文档

把 HTML 页面内容复制到飞书文档，排版最稳定，也能评论和协作。

上传到飞书云盘

把 HTML 作为文件上传并分享；适合下载查看，但在线预览能力取决于飞书设置。

静态托管成网页

放到团队可访问的静态站点、对象存储、内部门户或 GitHub Pages，再把 https 链接贴进飞书。
