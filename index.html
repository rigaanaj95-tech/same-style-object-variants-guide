Workflow

Skill 如何工作

把“看图描述风格、写提示词、批量生成、筛选返工”压成一个稳定流程。

01

识别输入

确认参考图、目标物体或场景、数量、视角、用途和硬性约束。

02

提取风格

分析媒介、构图、配色、材质、线条、字体、光影和主体关系。

03

生成提示词

把风格 brief 转换成可直接用于 image2 或其他生图工具的 prompt。

04

筛选返工

围绕风格一致、物体可识别、构图可用、后续可编辑来判断。

How to use

调用方式

建议把触发词放在任务开头，并明确目标对象。其余信息越完整，方案越稳定。

最短调用

使用 $same-style-object-variants，帮我基于这张参考图生成同风格物体变体。
目标物体：一个沙发

完整调用

使用 $same-style-object-variants，基于这张参考图生成同风格场景变体。
目标场景：一个舒适的家居场景
数量：生成 3 个方向
用途：社媒海报素材
要求：跟随参考图画风，不要强制写实

安装方式

下载压缩包后解压，将 same-style-object-variants 文件夹复制到 Codex skills 目录。

mkdir -p ~/.codex/skills
cp -R same-style-object-variants ~/.codex/skills/

常用返工

  • 不要写实，严格跟随参考图的插画/平面/手绘风格。
  • 只参考当前这张图，不要继承历史生成结果。
  • 只生成 1 个主体物体，不要额外添加同类物体。
  • 文字只作为版式元素，不需要真实可读。

Illustration

参考图是红底手绘家居海报时，输出同样手绘、同样色彩节奏的家居场景。

Campaign
