Same Style Object Variants

一套把“参考图风格”迁移到新物体、场景或素材上的 Codex skill。它默认跟随当前参考图，不固定继承任何历史风格，也不强制写实。

Trigger $same-style

在任务开头写入触发词，Codex 会进入风格分析、提示词生成、批量变体与返工流程。

Principle Current image first.

每次都以当前参考图为唯一风格源，避免上一张图的风格污染新任务。

Package Ready to share with your team.

页面可直接贴到飞书文档；压缩包内包含 skill 文件、参考文档和安装说明。

Skill 如何工作

参考图是插画，就生成插画；参考图是产品摄影，才生成摄影感。核心不是“固定某种视觉”，而是把当前图里的风格 DNA 稳定迁移到新对象。

01

识别输入

确认参考图、目标物体或场景、数量、视角、用途，以及必须保留或避免的限制。

02

提取风格

分析媒介、构图、配色、线条、材质、字体、光影、留白和主体比例。

03

生成提示词

输出可直接用于 image2 或其他生图工具的 prompt、负面约束和变体策略。

04

筛选返工

围绕风格一致、对象可识别、构图可用、后续可编辑来判断和迭代。

如何调用

使用时只需要写出触发词和目标对象。数量、用途、是否写实、视角和约束越清楚，越能稳定得到可用方案。

最短调用

使用 $same-style-object-variants，帮我基于这张参考图生成同风格物体变体。
目标物体：一个沙发

完整调用

使用 $same-style-object-variants，基于这张参考图生成同风格场景变体。
目标场景：一个舒适的家居场景
数量：生成 3 个方向
用途：社媒海报素材
要求：跟随参考图画风，不要强制写实

安装方式

下载压缩包后解压，将 same-style-object-variants 文件夹复制到 Codex skills 目录。

mkdir -p ~/.codex/skills
cp -R same-style-object-variants ~/.codex/skills/

常用返工语句

  • 不要写实，严格跟随参考图的插画/平面/手绘风格。
  • 只参考当前这张图，不要继承历史生成结果。
  • 只生成 1 个主体物体，不要额外添加同类物体。
  • 文字只作为版式元素，不需要真实可读，不要出现品牌 logo。

适合的任务

这不是完整 UED 还原流程，而是专注于同风格变体：先读懂视觉风格，再替换对象或延展场景。

Illustration

红底手绘家居海报、生活方式插画、轻量卡通场景延展。

Catalog

黑白产品目录页、家具/灯具单品展示、极简品牌画册。

Campaign

促销海报素材、商业摄影组合、节日视觉和社媒传播图。

Version 02

透明底素材交付

第二版把“生成后必须保存到固定目录”加入流程：先用风格参考生成纯主体素材，再用干净色底抠成透明 PNG，避免模型预览丢失后只能靠截图找回。
